Adds `<pie-item-list>`: `<pie-item-summary>` rows with a details column, host actions, a clipped summary, the host's search highlights below it and an expand button that mounts the item's player. `details`, `actions` and `highlights` take a custom element tag name or a render function. The interface catalogs gain `player.list.expandA11y`.
