`tool-policy.unknownSupportId` describes the policy inputs, so it moves from toolbar decisions to `ResolvedEngineInputs.diagnostics`, computed once per change to the assessment, an item's settings or the registry's tools and reported whatever the PNP enforcement; registering a tool a profile names clears it and emits an `"inputs"` change, and `PnpPolicyResult.unmappedSupportIds` is removed. `ResolvedEngineInputs.assessmentExpected` says whether an unbound assessment is a misconfiguration, set through the engine's `assessmentOptional` argument. The PNP debugger reads the placement, `assessmentExpected` and the input diagnostics from the resolved inputs.
