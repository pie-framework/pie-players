The line reader keeps its place in the tool stack as it moves, returns focus to the control that opened it when it closes, and offers tap controls to move it and to change its reading window height, frame height and width one at a time, which wrap onto a second row in a narrow pane. Focus entering a tool mounted in the section toolbar no longer scrolls the page to the toolbar, and a tool dialog that closes on Escape marks the key handled.
