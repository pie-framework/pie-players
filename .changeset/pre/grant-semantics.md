A `true` test-administration override keeps an item or district requirement's mandate: the tool stays `required`, and a host gate that removes it raises `tool-policy.requiredToolBlocked`. With `pnpEnforcement: "off"`, a profile grant no longer makes a toolbar tool's start failure fatal; region features still count it. `RequiredToolBlockedDetails.rule` is typed as the requirement that mandates the tool.
