Default section and assessment persistence store a session only under an attempt id, and without one neither read nor write, so a later learner on a shared device no longer resumes the previous learner's session. A context provider that disconnects hands its subscribers to the nearest provider left, or back to itself when it reconnects, and the context events are built on the `Event` of their target's window, so a copy of pie-context loaded before a DOM emulator registered dispatches on it.
