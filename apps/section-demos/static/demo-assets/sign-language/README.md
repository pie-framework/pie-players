# Sign Language Demo Assets

- `signing-poster.svg`: Authored in-repo as the poster frame for the sign-language
  (ASL) region demo.

**No signing clip is bundled.** The demo's catalog cards point at
`sample-asl.mp4` in this directory, which is deliberately absent: PIE does not own
ASL video production, storage, or hosting — those are host responsibilities — and
a fabricated signing clip would misrepresent what real signed content looks like.

The poster therefore stands in for the recording, and everything the player owns
is still exercised: catalog extraction, resolution, PNP gating, the region's
placement and resize behavior, and its accessible naming.

To see playback, drop a real signing clip in this directory as `sample-asl.mp4`.
It is git-ignored by intent — do not commit one.
