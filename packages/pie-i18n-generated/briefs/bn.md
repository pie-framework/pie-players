# Bengali (bn) brief

Serves every Bengali host: the catalog is registered under the bare `bn`
tag, so `bn-BD` and `bn-IN` both widen to it. The register is deliberately
the **shared literary standard** that both sides of the border read
naturally: West Bengal textbook vocabulary with forms that are current in
Bangladesh too, and where the two standard colloquials differ on a
plural/verbal suffix, the West Bengal (`চলিত`, `গুলি` side) form is pinned
so the catalog is internally consistent.

## Register

- Controls carry the polite `-ুন` imperative standard in Bengali UI:
  `বন্ধ করুন` (close), `সংরক্ষণ করুন` (save), `জমা দিন` (submit),
  `সমাপ্ত করুন` (finish). No pronouns anywhere: never `আপনি`/`তুমি`.
- Sentences use impersonal written Bengali (`… করা যায়নি` for "could not
  be…", `… করা হয়েছে` for completed events) — the state-change
  announcements read as events, never as bare labels restating a control.
- Empty states use `এখনও কোনো … নেই` (no … yet), not a bare `নেই`.
- Whole sentences authored whole; no fragment assembly.

## Numerals (pinned decision)

**Bengali numerals (০–৯) in Bengali-authored prose; placeholders pass
through as the host renders them.** Bengali school materials write
numbers in Bengali digits, and this catalog follows them where the number
is part of the authored sentence: the protractor alt text reads ০ থেকে
১৮০ ডিগ্রি, every ১০ ডিগ্রি; `speedOptionsHelp` says ১ অন্তর্ভুক্ত করুন.
Interpolated values (`{count}`, `{position}`, `{total}`, `{percent}`,
`{degrees}`, `{pixels}`) are not rewritten — a host that renders ASCII
digits gets ASCII digits inside Bengali text, which is how Bengali
software renders interpolation today. Technical/literal keys stay ASCII
verbatim: sample rates (`8000 Hz`), format names (MP3, OGG, PCM), HTTP
placeholders, `/api/tts`, `en-US`, JSON field identifiers. The `°` and `×`
glyphs survive.

## Script

- Bengali script with correct conjuncts and vowel signs throughout
  (ক্যালকুলেটর, প্রশ্ন, বিভাগ, স্থানাঙ্ক, অনুচ্ছেদ, পর্যায় সারণি,
  প্রতিলিপি). No transliteration shortcuts: য-ফলা (্য) and র-ফলা (্র)
  are written where the word demands them.
- Counters use the classifier টি directly after the numeral:
  `{count}টি নিবন্ধ`, `{count}টি ছবি`, `আর {count}টি চেষ্টা` — no space
  before টি, one space between Bengali words, no space between a Bengali
  word and its punctuation.
- Curly quotes “” survive from the English glyphs; the dictionary lookup
  notices keep “{term}”. The provider-id strings keep the ASCII single
  quotes the English has: `'{id}'`.

## Plurals

- CLDR `bn` carries `one`/`other`: `one` covers 0, 1 and the 0.x decimals;
  `other` covers 2 and up. All six plural groups carry both categories with
  `{count}` in each.
- Bengali does not plural-mark a noun after a numeral, so the two
  categories' surface text is identical where the noun follows the count
  (`{count}টি নিবন্ধ`); the categories are kept so `Intl.PluralRules`
  resolves correctly for every runtime.

## Untranslated product names

PIE, PNP, TTS, SSML, WaveNet, Studio, Desmos, Polly, AWS, Google Cloud TTS,
Web Speech API, HTTP, JSON, API, MP3, OGG, PCM, Hz, and the code
identifiers inside dev prose (`assessment`, `requiredTools`,
`updateAssessment(...)`, `assessmentId:`, `sectionId:`, `attemptId:`,
`mode:`, the instrumentation record kinds `all`/`event`/`error`/
`metric`/`user-context`/`global-attributes`).

## A11y strings

Keys ending `A11y` are screen-reader operating instructions. Translate them
as complete, self-sufficient sentences — the learner hears them without
seeing the layout — and keep every keyboard instruction concrete. Latin key
names stay Latin where that is how Bengali keyboards label them: Shift,
PageUp, PageDown, Escape, +/-, U; arrow keys are অ্যারো কী.
