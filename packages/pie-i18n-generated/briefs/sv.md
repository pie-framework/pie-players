# Swedish (sv) brief

Serves every Swedish host: registered under the bare `sv` tag, so `sv`,
`sv-SE` and `sv-FI` all widen to it. A Finland-Swedish host wanting a
different flavour overrides per key through `customMessages`.

## Register

- Controls carry the imperative verb, the Swedish UI convention: `Stäng`,
  `Slå upp`, `Kontrollera svar`.
- Sentences address the learner as `du` where a subject is unavoidable
  (`innan du fortsätter`); otherwise impersonal passives (`svaret har
  sparats`).
- Whole sentences authored whole; no fragment assembly.

## Typography

- Swedish quotes are the right-hand double quotation mark on both sides:
  `”{term}”`. `…` kept.
- Colon suffixes attach without space in abbreviations (`API:et`,
  `PIE:s`), per Swedish convention.

## Untranslated product names

PIE, PNP, TTS, SSML, WaveNet, Studio, Desmos, Polly, AWS, Google Cloud TTS,
Web Speech API, HTTP, JSON, API, MP3, OGG, PCM. Signed-language names
translate (`Amerikanskt teckenspråk`).
